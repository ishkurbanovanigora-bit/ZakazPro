ZAKAZPRO — TELEGRAM FOOD ORDER BOT

1) ZIP faylni Extract qiling.
2) bot.py faylini oching.
3) TOKEN = "TOKENNI_SHU_YERGA_QOYING" qatoriga BotFather tokenini kiriting.
   Tokenni hech kimga yubormang.
4) RUN_BOT.bat faylini ikki marta bosing.
   Yoki PyCharm'da requirements.txt paketini o'rnating va bot.py ni Run qiling.
5) Telegram'da botga /start yuboring.
